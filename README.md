# Online Price Analyzer

A desktop app for comparing sample product prices across Amazon, Flipkart, and Meesho.

## Features

- Compare prices for a selected product
- Highlight the lowest price and show the price difference
- Sort the prices from low to high
- View a bar chart comparing shopping apps

## Requirements

- Python 3
- Tkinter (usually included with Python)
- Matplotlib

Install the Python dependency:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python OnlinePriceAnalyser.py
```

The prices in this project are sample values stored in the source code. They are
not fetched live from shopping websites.
